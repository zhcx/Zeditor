# Zeditor v0.6.9

> 发布日期：2026-11-14

本次更新围绕「资料库与复用」补齐了片段、模板、快速访问、富文本复制、标题编号与链接预览等高频编辑能力，同时完善了 AI 伴写、本地 Agent（新增 DeepSeek Harness 后端）与 macOS 适配，并统一了 Rust 代码格式与静态检查。

## 更新日志

### 资料库：片段、模板与快速访问

- **片段系统**：新增可复用的文本片段，支持 `日期`、`文件名`、`%cursor%`（插入后光标停留位置）等占位符，支持导入 / 导出 JSON。入口为工具栏「资料」组、功能菜单与命令面板。
- **笔记模板**：内置会议记录、日记、周报、技术方案等模板，可通过「功能 → 用模板新建…」一键创建文档。
- **快速访问置顶**：侧栏新增「快速访问」区，文件与文件夹右键即可置顶，点击直接打开，可随时取消置顶。
- **跨平台富文本复制**：功能菜单「复制为富文本」把 Markdown 渲染为内联样式 HTML 写入剪贴板，可直接粘贴到 Word、笔记应用等支持富文本的环境；在 WKWebView 拒绝 `ClipboardItem` 时自动回退到 `execCommand`。
- **标题自动编号**：阅读预览按 `1 / 1.1 / 1.1.1` 层级自动编号，仅影响预览、不改动文档源码（设置项 `editor.auto_number_headings`，默认关闭）。
- **链接悬浮预览**：悬停外部链接显示域名；本地笔记通过原生 `link_preview` 命令读取标题与开头摘要（设置项 `editor.link_preview`，默认开启）。

### AI 伴写与助手

- 伴写弹窗支持外部点击与 `Escape` 关闭，位置越界时自动翻转 / 收边。
- 源码模式下仅在内容变化时触发自动伴写，移动光标不再打扰；所见即所得改用原生 `input / beforeinput / compositionend` 事件，并在读不回选区时用块尾兜底。
- 状态栏新增「立即在当前光标生成」，不会覆盖用户显式关闭伴写的偏好。
- Agent 桥接的一次性文本任务停用工具插件，避免校对 / 伴写误触发工具而被中止。

### 本地 Agent 与 DeepSeek Harness

- 新增 **DeepSeek Harness（DSH）** 后端：以 headless `--json` 方式运行，接入 Magpie 网关模型，支持会话续聊与权限预设。
- Pi 后端增加热进程复用与 `--session` 启动，消除每回合冷启动与上下文过期告警；修复重试导致的重复「Pi 已开始处理」提示与失败误报，429 限流改为中文提示。
- 默认优先使用 Agent 模式，仅在 Agent 不可用时提示配置 AI 服务商；设置面板中 Agent 选项提前，「直接写入」提示可关闭并记忆。

### macOS 适配与本地化

- 资料库弹窗、Toast 与链接预览纳入 macOS 外观层：系统圆角、描边、材质模糊与强调色，并在「减少透明度」偏好下移除毛玻璃。
- 资料库样式改用统一的 `--ui-*` 主题令牌，修复暗色主题下弹窗白底深字的问题。
- 功能菜单「插入片段… / 用模板新建… / 复制为富文本」完成本地化，并注册原生加速键 `⌥⌘S` / `⌥⌘N` / `⌥⌘C`。
- 补齐 zh-CN / zh-TW / en / ja / ko 多语言词条，新增 macOS 适配测试。

### 维护

- 统一 Rust 代码格式（`cargo fmt`），并修复 `cargo clippy -D warnings` 告警（`manual_split_once`、`items_after_test_module`），发布质量门保持全绿。
