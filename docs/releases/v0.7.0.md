# Zeditor v0.7.0

> 发布日期：2026-11-21

本次更新聚焦「编辑器交互」与「macOS 兼容性」：修复所见即所得与源码对照的右键菜单、选区高亮和预览选区丢失问题，并系统性补齐 macOS（WKWebView）下的剪贴板读写与纯文本粘贴能力，让复制、剪切、粘贴在两种编辑模式下行为一致、失败有提示。

## 更新日志

### 右键菜单与选区修复

- **所见即所得右键菜单**：在表格单元格或段落内右键时，改用鼠标位置的真实文本节点与偏移定位块，选区不再被折叠，剪切、复制、粘贴、格式、表格等菜单项恢复可用。
- **源码对照选区颜色**：Monaco 主题只接受 `#rrggbb[aa]` 颜色，此前传入 `rgba()` 会回退为纯红；新增颜色归一化后再定义主题，选区恢复主题蓝色。
- **预览选区保留**：预览内存在非折叠选区时，点击不再跳转到源码行并抢走焦点，可以直接在预览中选择与复制。

### macOS 剪贴板与粘贴

- **统一剪贴板层**：新增共享剪贴板工具，按「异步 Clipboard API → `execCommand` → 原生命令」三级降级，修复 macOS WKWebView 下「复制为 HTML」「复制」「剪切」静默失败的问题；「剪切」只有真正写入剪贴板后才删除原文。
- **粘贴为纯文本**：右键菜单「粘贴为纯文本」此前与普通「粘贴」是同一实现，现独立处理——源码模式插入原文，所见即所得按块与表格上下文转义后插入，避免粘贴内容里的 Markdown 语法被重新解析。
- **粘贴失败有提示**：读不到剪贴板时提示改用 `⌘V` 并回焦编辑器，不再只是菜单关掉、光标不动。
- **原生读取兜底**：新增 `read_clipboard_text` 命令，macOS 使用 `pbpaste`、Windows 使用 `Get-Clipboard`、Linux 依次尝试 `wl-paste` / `xclip` / `xsel`。
- **光标定位兜底**：所见即所得的块定位支持 `caretPositionFromPoint`，兼容仅提供标准 API 的 WebKit / Firefox 环境。
- **快捷键提示平台化**：设置面板与块源码编辑器的快捷键说明改走平台格式化，macOS 上正确显示 `⌥⌘M`、`⌘Enter`。

### 维护

- 版本号升级至 `0.7.0`，同步应用与构建配置版本。
- 新增 macOS 剪贴板与纯文本粘贴回归测试，发布质量门（lint / test / build / clippy / fmt）保持全绿。
