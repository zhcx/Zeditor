# Zeditor v0.7.1

> 发布日期：2026-11-28

本次更新将 Textus 写作工作流合并到主线，把 AI 伴写、修改审阅、本地版本、知识索引与双文档编辑整合为连续的工作流，同时扩展 MCP 客户端接入并完成 macOS 打包与分栏兼容加固。

## 写作与审阅

- **AI Ghost Text 伴写**：在光标处展示续写建议，按 `Tab` 接受；光标、文档或修订号变化后自动失效，避免把旧建议插入新位置。
- **逐块修改审阅**：AI 修改以 hunk 差异呈现，可逐块接受或拒绝；接受前不写正文，一次接受对应一次撤销。
- **选区批注**：支持在选区上添加批注、定位、解决 / 重新打开、删除与 JSON 导出；当前批注持久化在本地 `localStorage`。
- **双编辑器一致体验**：Monaco 源码编辑器与所见即所得共用审阅适配，MCP `selection_set` 默认进入审阅流程。

## 本地历史与知识网络

- **耐久本地版本库**：保存文档历史并保留原始编码，支持去重、预览、删除与恢复；重命名与另存为使用不同迁移策略。
- **元数据与反向链接**：增量索引标题、Frontmatter、链接、标签、任务与块 ID，支持 Wiki 自动补全、未链接提及与反向链接。
- **知识管理视图**：新增 Frontmatter 属性编辑、Database 表格 / 看板、跨文档任务、日历、今日日记和 SVG 笔记关系图。
- **迁移与导入**：支持 Obsidian vault 只读分析、Notion HTML 导入和 Typora CSS 校验；大工作区扫描会提示部分索引范围。

## 分栏与项目上下文

- **双文档分栏**：同一工作区可左右或上下同时编辑两篇文档，支持独立保存、拖动调整比例和键盘调整。
- **原生菜单焦点路由**：macOS 原生保存、另存为、撤销和重做跟随当前聚焦编辑器，不改变活动标签页归属。
- **项目 AI 上下文**：项目文风、写作要求、资料库、技能和记忆随工作区加载；切换工作区自动清空，未保存文档不继承项目上下文。
- **安全插件 MVP**：支持声明式命令、斜杠命令和纯文本面板；拒绝任意 JavaScript、远程入口以及未声明的文件系统和网络权限。

## MCP 与 macOS

- **更多 MCP 客户端**：在 Claude Desktop、Claude Code、Codex CLI、Gemini CLI 之外，新增 Pi、DeepSeek Harness、WorkBuddy、Qoder / Qoder CN 和通用 Harness 配置。
- **sidecar 随包发布**：MCP server 自动增量构建并打包到各平台安装包，避免开发环境可用、安装后缺失。
- **稳定的连接自检**：持续排空 sidecar stderr 并保留有界诊断信息，避免日志写满管道后阻塞握手。
- **macOS 分栏加固**：恢复源码 / 预览横向布局，修复原生菜单焦点目标残留和 Monaco model 释放。
- **macOS 测试兼容**：修正 `/var` 符号链接导致的临时目录误判，并保留符号链接逃逸防护测试。

## 维护与质量

- 应用版本升级至 `0.7.1`，同步 npm、Cargo、Tauri 和锁文件版本；文档转换模块保持独立版本 `1.3.0`。
- 新增分栏、焦点路由、sidecar 构建、MCP 诊断和 macOS 路径回归测试。
- 发布质量门继续执行 lint、测试、前端构建、Rust 格式检查、Clippy 和 Rust 测试。
