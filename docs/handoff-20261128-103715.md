### 已完成范围

第一阶段：写作与审阅闭环

- 正文内 AI Ghost Text，`Tab` 接受；光标、文档或 revision 变化后失效。
- AI 修改按 hunk 接受/拒绝，接受前不写正文，一次接受对应一次撤销。
- 选区批注、定位、解决/重新打开、删除、JSON 导出；当前持久化到 `localStorage`。
- Monaco 与 WYSIWYG 共用审阅适配；MCP `selection_set` 默认进入审阅。

第二阶段：历史与知识索引

- 新增耐久本地版本库，支持编码保留、去重、预览、删除、恢复。
- 区分重命名与另存为，避免另存为误迁移原文件历史。
- 增量 Markdown 元数据索引：标题、frontmatter、链接、标签、任务、块 ID。
- Wiki 自动补全、未链接提及、增量反向链接。
- 双文档左右/上下分栏、独立保存、比例调整。
- 只读扫描命令不扩大破坏性文件权限；扫描超过 3000 篇会明确提示部分索引。

第三阶段：项目 AI 配置与安全插件

- 项目文风、写作要求、资料库、技能和记忆上下文。
- 上下文随工作区加载，切换工作区清空；未保存文档不继承项目上下文。
- 保存使用版本校验与代次检查，外部修改时拒绝覆盖。
- 常见 API Key、Bearer Token、GitHub Token、URL 凭据脱敏。
- 声明式安全插件 MVP：命令、斜杠命令、纯文本面板；拒绝任意 JS、远程入口、文件系统和网络权限。

第四阶段：知识管理视图

- Frontmatter 属性编辑，保留注释和未知字段。
- Database 表格/看板、状态筛选、JSON 导出。
- 跨文档任务筛选与勾选保存。
- 日历、日期条目、今日日记创建。
- SVG 笔记关系图。
- Obsidian vault 只读分析、Notion HTML 导入、Typora CSS 校验。

### 关键架构与不变量

- `src/types/editor.ts`：`EditorController` 的可选审阅适配方法，旧 controller/mock 无需实现。
- `src/utils/reviewModel.ts`：hunk diff、提案快照/revision 校验、批注锚点、ghost Tab 判定。
- `src/stores/aiStore.ts`：所有 AI 编辑请求统一附带项目上下文；接受前不写正文。
- `src/components/Editor/Editor.tsx`、`src/components/Wysiwyg/*`：Monaco 与 WYSIWYG 的非 mutating 装饰、早期 Tab 拦截、同步写回。
- `src-tauri/src/local_history.rs`：本地历史与 recovery、WebDAV/S3 版本分离；按实际编码读写。
- `src/services/knowledgeIndex.ts`、`src/utils/metadataIndex.ts`：共享增量索引；增量更新会取消旧全量扫描，避免旧快照覆盖新编辑。
- `src/services/projectContext.ts`、`src/stores/projectContextStore.ts`：工作区绑定、版本校验、排他创建、敏感信息脱敏。
- `src/utils/pluginManifest.ts`、`src/stores/pluginStore.ts`：只接受白名单声明式贡献。
- `src/components/Editor/SecondaryEditor.tsx`、`SplitEditorWorkspace.tsx`：分栏使用独立 Monaco 实例，输入立即同步，保存前再次 flush。
- `src/App.tsx`：活动栏、事件和主工作台总装；`WorkspaceSync` 负责历史、索引和项目上下文同步。

## Next steps / 下一步（优先级）

1. **安装包真机冒烟测试**：在干净 Windows 用户配置中安装 NSIS/MSI，验证首次启动、文件关联、AI 设置、知识侧栏和分栏；本轮只做了浏览器前端验证和安装包结构测试。
2. **发布前质量门**：安装 Rust Clippy 组件后运行 `cargo clippy --locked --all-targets -- -D warnings`；升级版本号，补 CHANGELOG/发布说明，再创建 PR，走现有 GitHub Actions/SignPath 发布流程。
3. **持久化审阅数据**：将批注从 `localStorage` 迁移到文档旁 sidecar 或应用数据目录，处理重命名、另存为、删除和冲突。
4. **插件安全运行时**：在声明式 MVP 之后设计 sandbox iframe/独立进程、双重权限校验、市场签名/哈希和故障熔断；不要直接在主 WebView 执行第三方 JS。
5. **知识管理增强**：Database 公式/关系/汇总、Graph 力导向布局、任务提醒与重复任务、Typora 主题实际应用。
6. **自动化与性能**：为 Review、Knowledge、Split 增加浏览器回归；对 3000+ 文档工作区做索引、扫描取消、内存和首屏性能基准。
7. **已知小问题**：`LocalHistoryStore::migrate` 在目标文档已有历史时直接失败，前端会吞掉错误；如需完整重命名迁移，应设计合并策略和可见提示。

注意：`src/App.tsx` 保留 CRLF；默认 `git diff --check` 可能把 CR 报为行尾空白。使用：

```bash
git -c core.whitespace=cr-at-eol diff --check
```

```bash
git -c http.sslBackend=openssl push -u origin feature/textus-writing-workflow
```
